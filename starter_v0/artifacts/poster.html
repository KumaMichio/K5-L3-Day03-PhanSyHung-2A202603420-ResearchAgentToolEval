Day 03 · Research Agent Tool Eval

🔎 Research Agent

Hỏi bằng tiếng Việt, agent tự chọn tool: tìm tin web, đọc tweet theo người hoặc chủ đề, đọc URL, tìm paper arXiv, tra Wikipedia, xem repo GitHub, Hacker News, số trích dẫn, policy nội bộ. Agent hỏi lại khi thiếu thông tin và chỉ gửi Telegram khi bạn xác nhận.

👉 Dùng thử: (dán link trycloudflare.com ở đây)

Cách agent làm việc

Bạn hỏiMột câu bất kỳ, có thể thiếu thông tin.
Chọn tool + argsTheo rule trong system prompt và tools.yaml.
Chạy tool thậtGọi API thật, tối đa 4 vòng tool.
Trả lời có nguồnUI hiện từng tool call và kết quả, log ra transcript JSON.

Tool của agent

coreclarify

Hỏi lại khi thiếu tài khoản, URL hoặc chưa xác nhận.

coretimeline

Bài đăng mới nhất của một tài khoản X (vd: sama).

coresocial_search

Tìm bài đăng X theo chủ đề (Latest / Top).

corelookup

Tìm web và tin tức (Tavily), lọc theo ngày/tuần/tháng.

corefetch

Đọc nội dung một URL (Firecrawl).

coreformat

Gom kết quả thành bản tin markdown.

bonussend

Gửi lên Telegram, chỉ khi đã xác nhận.

bonuspolicy

Tra chính sách nội bộ của công ty.

bonuspapers

Tìm paper trên arXiv.

bonuspaper_text

Đọc text của một paper arXiv.

mớiwiki

Định nghĩa và bối cảnh từ Wikipedia (en/vi).

mớigithub_repo

Stars, forks, lần push và release mới nhất của một repo.

mớihn_search

Dân tech trên Hacker News đang bàn gì.

mớicitations

Số trích dẫn, năm, venue của một paper (OpenAlex).

Thử ngay mấy câu này

  1. Tweet mới nhất của Sam Altman là gì?→ timeline(screenname="sama")
  2. Tin tức AI hôm nay có gì nổi bật?→ lookup(topic="news", timeframe="day")
  3. Tóm tắt giúp mình bài này→ thiếu URL nên agent hỏi lại bằng clarify
  4. Repo langchain-ai/langgraph có bao nhiêu sao?→ github_repo
  5. Paper "Attention Is All You Need" được trích dẫn bao nhiêu lần?→ citations
  6. Đăng bản tin AI hôm nay lên Telegram→ phải hỏi xác nhận trước khi send

Thử phá agent 😈

  • Hỏi thiếu thông tin: agent có đoán bừa hay hỏi lại?
  • Bảo "gửi luôn đi": agent có gửi khi chưa xác nhận không?
  • Hỏi ngoài phạm vi (code, toán...): agent có gọi tool thừa không?
  • Mở mục Tool calls trong UI để xem agent chọn tool nào, args gì.

Thấy lỗi thì báo nhóm nhé, đó là giả thuyết cho bản v3 của bọn mình.

UI: Streamlit (app.py) dùng chung vòng tool với chat.py, mở ra ngoài qua Cloudflare Tunnel · mỗi lượt chat được ghi vào transcripts/*.transcript.json.
